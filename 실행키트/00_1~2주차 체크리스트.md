# 실행키트: 1~2주차 체크리스트

실행 플랜 v2의 1~2주차(측정 구조 구축 + 광고 재개 준비)를 실제로 끝내기 위한 체크리스트입니다. 상호명이 정해지기 전에도 할 수 있는 일은 `[상호명]` 자리표시로 두고 먼저 진행합니다.

## 이 폴더의 파일

| 파일 | 용도 | 언제 쓰나 |
|---|---|---|
| `01_측정 규칙과 ERP 설계.md` | UTM 이름 규칙, ERP 단계·필수 칸, "유효상담" 정의 | 1주차에 ERP·랜딩에 반영 |
| `02_광고 캠페인 구조.md` | 네이버 파워링크 광고그룹·키워드·제외키워드, 메타 구조와 소재 문구 5개 | 3주차 광고 재개 전 세팅 |
| `03_리드 응대 스크립트.md` | 알림톡 템플릿 3종, 첫 통화 스크립트, D0~D10 연락 일정, 자주 나오는 반론 대응 | 2주차 알림톡 신청, 3주차부터 매일 |
| `04_견적폼과 동의문구.md` | 견적 폼 필드, 동의 4종 문구 초안, 랜딩 하단 표시사항 | 2주차 랜딩 변형 시 |
| `05_Claude 프로젝트 지침.md` | Claude 앱 프로젝트 4개에 붙여넣을 지침 | 1주차에 만들어 두고 매주 사용 |
| `주간 성과 시트.xlsx` | 매주 채널별 입력 → 판정(중단/유지/증액), 월 손익 | 3주차부터 매주 월요일 |

## 1주차

- [ ] **상호명 확정**: 후보 2~3개로 압축 → 키프리스(39류·36류) → 네이버 검색 → 도메인·SNS ID → 지인 5명 테스트 (`reports/상호명 후보 정리.md`)
- [ ] **수수료표 정리**: 금융사·대리점별 건당 수수료, 환수 조건(기간·비율·사유), 지급 시점 → `주간 성과 시트.xlsx`의 `가정` 시트 m 값 점검
- [ ] **측정 규칙 확정**: `01` 문서의 UTM 규칙과 ERP 단계를 ERP 담당(또는 본인)이 반영할 수 있는지 확인
- [ ] **키워드 조회**: 네이버 검색광고 → 도구 → 키워드도구에서 `02` 문서의 후보 키워드 월간 검색수·평균 클릭비용 확인 후 표에 기입
- [ ] **Claude 프로젝트 4개 생성**: `05` 문서 지침 붙여넣기, 설정에서 모델 학습 사용 끄기

## 2주차

- [ ] 사업자등록(상호 확정 후) / 통신판매업 신고 문의(시·군·구청: 결제 없는 중개의 구매안전서비스 비대상 처리 여부)
- [ ] 리스 모집인 등록 절차 진행(여신금융협회)
- [ ] 카카오톡 채널 개설 → 비즈니스 인증 → 알림톡 발송 대행사(예: 솔라피) 가입 → `03` 문서의 템플릿 3종 심사 신청
- [ ] 랜딩 변형: `04` 문서의 폼 필드·동의 4종·하단 표시사항 반영, UTM 값이 ERP로 넘어가는지 확인
- [ ] n8n(또는 Make) 최소 흐름: 폼 접수 → ERP 저장 → 고객 알림톡 즉시 발송 → 텔레그램 알림(기존)
- [ ] **테스트 리드 5건**: 각기 다른 UTM으로 폼 제출 → 1분 안에 ERP·알림톡·텔레그램까지 도착하는지, 출처가 정확히 찍히는지 확인
- [ ] 기존 고객(올해 19명 + 이전 고객)에게 안부 연락 + 출고 사례 콘텐츠 사용 동의 요청 + 만기일 ERP 입력

- [ ] 전화 집중 시간(10:00~13:30, 18:00~21:00) 캘린더에 고정
