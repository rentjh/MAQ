# 실행키트: 1~2주차 체크리스트

실행 플랜 v2의 1~2주차(측정 구조 구축 + 광고 재개 준비)를 실제로 끝내기 위한 체크리스트입니다. **광고는 당장 집행하지 않고, 집행 전에 세팅을 끝내 두는 것**이 목적입니다. 콘텐츠(블로그·숏폼)는 광고와 무관하게 지금부터 병행합니다. 상호명이 정해지기 전에도 할 수 있는 일은 `[상호명]` 자리표시로 두고 먼저 진행합니다.

## 1주차

- [ ] **상호명 확정**: 후보 2~3개로 압축 → 키프리스(39류·36류) → 네이버 검색 → 도메인·SNS ID → 지인 5명 테스트 (`reports/상호명 후보 정리.md`)
- [ ] **견적 수수료 기준 정하기**: 수수료를 견적마다 자유롭게 넣는 방식이므로, 채널별 기준을 미리 정해 둡니다. 예) 표준 수수료(평소), 최소 수수료(이 아래로는 받지 않음), 광고 유입 고객용 수수료(비교 견적 경쟁이 심하므로 별도). 정한 표준값에서 판촉비를 뺀 금액이 `주간 성과 시트.xlsx` `가정` 시트의 건당 순공헌 m입니다. 계약마다 실제 수수료와 판촉비를 ERP에 남기면 채널별 실제 m이 나옵니다.
- [ ] **측정 규칙 확정**: `01` 문서의 UTM 규칙과 ERP 단계를 ERP 담당(또는 본인)이 반영할 수 있는지 확인
- [ ] **키워드 조회 자동화**: 네이버 검색광고 API 키 발급 → 환경 변수 등록 → `도구/네이버키워드/naver_keywords.py`로 후보 키워드의 검색수·클릭수·경쟁도·순위별 예상 입찰가를 한 번에 조회 (`도구/네이버키워드/사용법.md`)
- [ ] **Claude 프로젝트 4개 생성**: `05` 문서 지침 붙여넣기, 설정에서 모델 학습 사용 끄기

## 2주차

- [ ] 사업자등록(상호 확정 후) / 통신판매업 신고 문의(시·군·구청: 결제 없는 중개의 구매안전서비스 비대상 처리 여부)
- [ ] 리스 모집인 등록 절차 진행(여신금융협회)
- [ ] 카카오톡 채널 개설 → 비즈니스 인증 → 알림톡 발송 대행사(예: 솔라피) 가입 → `03` 문서의 템플릿 3종 심사 신청
- [ ] 랜딩 변형: `04` 문서의 폼 필드·동의 4종·하단 표시사항 반영, UTM 값이 ERP로 넘어가는지 확인
- [ ] n8n(또는 Make) 최소 흐름: 폼 접수 → ERP 저장 → 고객 알림톡 즉시 발송 → 텔레그램 알림(기존)
- [ ] **테스트 리드 5건**: 각기 다른 UTM으로 폼 제출 → 1분 안에 ERP·알림톡·텔레그램까지 도착하는지, 출처가 정확히 찍히는지 확인
- [ ] 기존 고객(올해 19명 + 이전 고객)에게 안부 연락 + 출고 사례 콘텐츠 사용 동의 요청 + 만기일 ERP 입력

## 콘텐츠 병행 (1주차부터)

- [ ] 네이버 블로그·인스타·유튜브·카카오톡 채널 계정 만들기(상호명 확정 후 이름 반영)
- [ ] 주 2편 블로그 + 주 2편 세로 영상 시작: 실제 고객 사례 없이도 쓸 수 있는 **정보형 주제**부터(렌트 vs 리스 vs 할부, 광고 속 월 납입금의 진짜 조건, 사업자 비용처리 기초 등)
- [ ] `05` 문서의 "콘텐츠 공장" 프로젝트로 초안 → 본인 경험·판단 추가 → 직접 발행
