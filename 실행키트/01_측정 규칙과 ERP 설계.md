# 01. 측정 규칙과 ERP 설계

목표: **첫 리드부터 "어디서 왔고, 어디까지 갔고, 얼마 들었는지"가 자동으로 남게** 합니다. 과거 광고가 판단 불가로 끝난 원인을 처음부터 막는 장치입니다.

## 1. UTM 이름 규칙

모든 광고·콘텐츠 링크에 아래 3개 값을 붙이고, 랜딩 폼이 이 값을 숨김 필드로 ERP에 함께 보냅니다.

| 파라미터 | 규칙 | 허용 값 |
|---|---|---|
| `utm_source` | 채널(소문자, 고정 목록) | `naver_sa` `naver_gfa` `meta` `blog` `clip` `shorts` `reels` `kakao` `referral` `db` |
| `utm_campaign` | 광고그룹·주제(소문자, 하이픈) | 예: `model-rent`, `biz-tax`, `lease`, `quote-reveal` |
| `utm_content` | 소재·글 번호 | 예: `a01`, `a02`, `post-0107` |

예시
- 파워링크 차종 그룹: `https://[도메인]/?utm_source=naver_sa&utm_campaign=model-rent&utm_content=kw`
- 메타 소재 2번: `...?utm_source=meta&utm_campaign=quote-reveal&utm_content=a02`
- 블로그 7번째 글 하단 링크: `...?utm_source=blog&utm_campaign=info&utm_content=post-0007`

규칙
- 대문자·한글·공백 금지(집계가 갈라짐).
- 네이버 파워링크는 키워드 단위 추적을 위해 `utm_content={keyword}` 대신 네이버 자동 추적 파라미터(`n_keyword`) 사용을 우선 검토.
- **전화·카톡 직접 문의**는 첫 통화에서 "어디서 보고 연락 주셨어요?"를 묻고 ERP 출처 칸에 위 목록 중 하나로 입력.
- 구매 DB는 `db`, 지인·기존 고객 소개는 `referral`로 통일.

## 2. ERP 단계 (고정)

| 단계 | 정의 | 다음 행동일 기본값 |
|---|---|---|
| 1 신규 | 접수됨, 아직 통화 전 | 당일 |
| 2 연결 | 통화 성공(본인 확인) | 당일~+1일 |
| 3 유효상담 | **통화 연결 + 희망 차종(또는 차급) + 희망 시기 + 자금 방식(보증금/선납/무보증 등) 3가지 확인** | +1일 |
| 4 견적발송 | 비교 견적을 실제로 보냄 | +2일 |
| 5 심사 | 금융사 심사 접수 | 심사 결과일 |
| 6 계약 | 계약서 작성 완료 | 출고 예정일 |
| 7 출고 | 차량 인도 | +7일(감사 연락) |
| 장기관리 | 6회 연락 무응답 또는 "나중에" | +30일 |
| 이탈 | 타사 계약·구매 포기 등 | 없음 |

**유효상담 기준은 바꾸지 않습니다.** 기준이 흔들리면 채널 비교가 무의미해집니다.

## 3. ERP 필수 칸

| 칸 | 입력 | 비고 |
|---|---|---|
| 리드 ID | 자동 | AI 작업 시 이름·번호 대신 이 ID만 사용 |
| 접수 일시 | 자동 | |
| 출처 / 캠페인 / 소재 | 자동(UTM) 또는 수기 | 1장 목록 값만 |
| 첫 통화 일시 | 수기 또는 자동 | 응답 속도 측정 |
| 연락 시도 횟수 | 수기 | 6회 기준 |
| 단계 | 선택 | 2장 표 |
| **다음 행동일** | 날짜 | **빈칸 금지.** 매일 아침 콜 리스트의 기준 |
| 희망 차종 / 렌트·리스 / 개인·사업자·법인 / 희망 시기 | 폼 + 통화 | |
| 이탈 사유 | 선택: 가격 / 심사 / 연락두절 / 타사 계약 / 구매 보류 / 허위·장난 / 기타 | |
| 판촉비 | 금액 | 계약 건만 |
| 수수료 | 금액 | 계약 건만, 출처별 실제 m 계산용 |
| 만기일 | 날짜 | 출고 고객 |
| 광고 수신 동의 / 야간 수신 동의 | 예/아니오 | 광고성 메시지 발송 가능 여부 |

## 4. 매주 월요일 기록 (10분)

1. 네이버 검색광고·GFA·메타 광고관리자에서 지난주(월~일) 소진액을 채널별로 확인(VAT 별도로 통일)
2. ERP에서 지난주 접수 리드를 출처별로 집계: 리드 / 연결 / 유효상담 / 견적발송 / 계약 / 판촉비
3. `주간 성과 시트.xlsx` → `주간기록`에 채널별 한 줄씩 입력
4. `채널요약` 시트의 판정 확인 → Claude "광고 분석가" 프로젝트에 두 시트를 붙여넣고 이번 주 조정안 받기
5. 예산 변경은 본인이 직접 실행

## 5. 매일 아침 (10분)

ERP에서 "다음 행동일 ≤ 오늘" 목록을 뽑아 우선순위대로 통화:
1. 신규(접수 후 미통화) → 2. 견적발송 후 회신 대기 → 3. 유효상담 → 4. 연결만 됨 → 5. 장기관리 중 오늘 날짜
