# 03. 리드 응대 스크립트

목표: 업무시간 리드는 **5분 안에 첫 통화**, 업무시간 외 리드는 다음 날 첫 통화 시간대에 가장 먼저.

## 1. 알림톡 템플릿 3종 (카카오 심사용 초안)

알림톡은 **정보성 메시지만** 가능합니다. 할인·프로모션·"지금 신청" 같은 광고 문구를 넣으면 심사에서 반려됩니다. `#{변수}`는 발송 대행사 규격에 맞춰 바꾸세요.

**① 접수 확인 (업무시간)**
```
[상호명] 견적 상담 접수 안내

#{이름}님, 견적 상담 요청이 접수되었습니다.

- 접수 차종: #{차종}
- 담당자: #{담당자} (#{담당자번호})

담당자가 곧 전화드리겠습니다. 통화가 어려우시면 편한 시간을 이 채팅으로 남겨 주세요.
```

**② 접수 확인 (업무시간 외)**
```
[상호명] 견적 상담 접수 안내

#{이름}님, 견적 상담 요청이 접수되었습니다.

- 접수 차종: #{차종}
- 연락 예정: #{연락예정일시}

예정 시간이 불편하시면 편한 시간을 이 채팅으로 남겨 주세요.
```

**③ 부재 시 안내 (통화 실패 후)**
```
[상호명] 상담 연락 안내

#{이름}님, 요청하신 견적 상담 건으로 연락드렸으나 통화가 되지 않았습니다.

편한 시간을 이 채팅으로 남겨 주시면 그 시간에 다시 연락드리겠습니다.
- 담당자: #{담당자} (#{담당자번호})
```

## 2. D0~D10 연락 일정

| 시점 | 행동 | 채널 |
|---|---|---|
| D0 즉시 | 알림톡 ① 또는 ② (자동) | 알림톡 |
| D0 5분 내 | 1차 통화 | 전화 |
| D0 +1시간 | 2차 통화, 실패 시 알림톡 ③ | 전화+알림톡 |
| D0 저녁(18~21시) | 3차 통화 | 전화 |
| D1 | 4차 통화 | 전화 |
| D3 | 5차 통화 + 문자("견적 준비해 두었습니다, 편한 시간 알려주세요") | 전화+문자 |
| D7 | 6차 통화 | 전화 |
| D10 | 무응답이면 "장기관리"로, 다음 행동일 +30일 | — |

광고성 문자(혜택·프로모션 안내)는 **광고 수신 동의자에게만**, 21시~08시는 **별도 야간 동의자에게만**, 문자 앞에 "(광고)" 표시와 무료 수신거부 방법을 넣습니다.

## 3. 첫 통화 스크립트 (3~5분)

**① 인사·확인 (20초)**
"안녕하세요, [상호명] [이름]입니다. 방금 [차종] 견적 문의 주셔서 연락드렸어요. 지금 3분 정도 통화 괜찮으세요?"
→ 안 되면: "언제 다시 전화드리면 될까요?" → 다음 행동일 입력

**② 출처 확인 (5초)** — 폼에 출처가 없을 때만
"혹시 어디서 보고 문의 주셨어요?"

**③ 유효상담 3가지 확인 (1~2분)**
1. 차: "차종은 [차종]으로 정하신 거예요, 아니면 비교 중이세요?"
2. 시기: "언제쯤 타실 계획이세요? 지금 차 계약 만기가 있으세요?"
3. 자금: "초기 비용은 보증금이나 선납금을 넣으실 생각이세요, 아니면 무보증 쪽이세요?"
+ "개인이세요, 사업자세요?" / "렌트랑 리스 중에 생각하신 게 있으세요?"

**④ 차별점 한 줄 (20초)**
"저는 금융사 여러 곳 조건을 같은 기준으로 비교해서, 보증금·선납·주행거리까지 다 적힌 견적으로 보내드려요. 계약 후 만기까지 제가 직접 챙깁니다."

**⑤ 다음 약속 (20초)**
"오늘 [시간]까지 비교 견적 정리해서 카톡으로 보내드릴게요. 보시고 [내일 몇 시]에 제가 다시 전화드려도 될까요?"
→ ERP: 단계 "유효상담", 다음 행동일 입력

## 4. 자주 나오는 반론

| 고객 말 | 대응 |
|---|---|
| "광고엔 월 10만 원대던데요?" | "그 금액은 보통 선납금을 차값의 30~50% 넣는 조건이에요. 같은 조건으로 계산해 드리고, 무보증일 때 금액도 같이 보여드릴게요." |
| "다른 데서도 견적 받고 있어요" | "좋아요, 비교하시는 게 맞아요. 다른 견적 받으시면 보증금·선납·주행거리·만기 인수 조건이 같은지만 확인해 보세요. 제가 같은 기준으로 맞춰 비교해 드릴 수도 있어요." |
| "그냥 문자로 보내주세요" | "네, 견적 보내드릴게요. 정확하게 하려면 두 가지만 여쭤볼게요: 초기 비용 방식이랑 연간 주행거리요." |
| "신용이 걱정돼요" | "가능 여부부터 확인하는 게 순서예요. 무리한 약속은 안 드리고, 가능한 조건만 안내해 드릴게요." (심사 결과를 약속하지 않음) |
| "생각해 볼게요" | "네, 충분히 보세요. 그럼 [날짜]에 제가 한 번만 연락드려도 될까요?" → 다음 행동일 입력 |

## 5. 출고 후 관리

| 시점 | 내용 |
|---|---|
| 출고 +7일 | 감사 연락, 불편 사항 확인, **출고 사례 콘텐츠 사용 동의** 요청 |
| 출고 +3개월 | 안부, 정비·보험 문의 확인, "주변에 차 알아보는 분 계시면 편하게 연결해 주세요" |
| 출고 +1년 | 안부 |
| 만기 -6/-3/-1개월 | 만기 옵션(반납·인수·재계약) 안내, 재견적 |

소개 보상은 **렌트 계약에 한해, 대리점·금융사 확인 후** 운영합니다. 리스는 금소법상 고객에게 재산상 이익 제공이 제한될 수 있습니다.
