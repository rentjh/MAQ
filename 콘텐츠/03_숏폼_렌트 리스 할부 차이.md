# [숏폼 1] 렌트·리스·할부, 30초 정리

- **길이**: 35~40초 / **비율**: 9:16 세로
- **촬영**: 본인이 화면에 나와서 말하기(얼굴 or 상반신). 손에 종이 한 장(3칸 표)을 들거나 화면에 자막으로 표 띄우기
- **업로드**: 네이버 클립, 유튜브 쇼츠, 인스타 릴스, 카카오 숏폼 (같은 영상)
- **편집**: Vrew 또는 CapCut 자동 자막 → 핵심 단어만 색 강조
- **원본 블로그**: `01_블로그_렌트 리스 할부 4년 총비용.md`

## 대본

| 시간 | 말하기 (그대로 읽기) | 화면 자막 / 연출 |
|---|---|---|
| 0~3초 | "렌트, 리스, 할부. 뭐가 제일 싸냐고요? 월 납입금으론 몰라요." | **월 납입금으론 몰라요** (크게) |
| 3~10초 | "장기렌트는 보험이랑 세금이 다 들어가 있어요. 번호판은 하·허·호예요." | 장기렌트 = 보험·세금 포함 / 하·허·호 번호판 |
| 10~16초 | "리스는 일반 번호판이고, 보험은 내 이름으로 따로 들어요. 보험 경력이 이어지죠." | 리스 = 일반 번호판 / 보험 내 명의 |
| 16~22초 | "할부는 처음부터 내 차예요. 대신 취득세, 보험, 세금 다 내가 내요." | 할부 = 내 차 / 세금·보험 내가 |
| 22~30초 | "그래서 보험료 비싸게 나오는 분은 렌트가, 보험료 싼 분은 리스나 할부가 유리할 때가 많아요." | 보험료 비싸면 → 렌트 / 싸면 → 리스·할부 |
| 30~37초 | "제일 정확한 건 같은 차, 같은 조건으로 4년 총비용을 뽑아 보는 거예요." | **4년 총비용으로 비교** |
| 37~40초 | "조건 남겨 주시면 세 가지 다 같은 기준으로 비교해 드릴게요." | 프로필 링크에서 견적 비교 신청 |

## 업로드 문구 (설명란)

```
렌트 vs 리스 vs 할부, 월 납입금 말고 4년 총비용으로 비교하세요.

✔ 장기렌트: 보험·세금 포함, 하·허·호 번호판
✔ 리스: 일반 번호판, 보험 내 명의
✔ 할부: 내 차, 세금·보험 직접

내 조건(차종·초기 비용·주행거리)으로 같은 기준 비교 → 프로필 링크

#장기렌트 #자동차리스 #신차할부 #장기렌트리스차이 #신차견적
```

- 첫 3초에 바로 결론 문장. 인사("안녕하세요")로 시작하지 않기
- 자연광 창가, 휴대폰은 눈높이, 배경은 깔끔하게(사무실 책상 or 차 앞)
