# [숏폼 2] "월 10만 원대" 광고의 진짜 조건

- **길이**: 35~45초 / **비율**: 9:16 세로
- **촬영**: 본인 얼굴 + 손가락으로 4개를 하나씩 접으며 설명 (또는 화면 녹화로 계산기 보여주기)
- **업로드**: 네이버 클립, 유튜브 쇼츠, 인스타 릴스, 카카오 숏폼
- **원본 블로그**: `02_블로그_월 10만원대 광고의 진짜 조건.md`
- **주의**: 특정 업체 광고 화면을 보여주지 않기. 차종명은 "OO" 또는 본인이 직접 계산한 차로만

## 대본

| 시간 | 말하기 | 화면 자막 / 연출 |
|---|---|---|
| 0~3초 | "월 10만 원대 장기렌트, 진짜일까요? 진짜예요. 조건이 붙어 있을 뿐." | **진짜예요. 조건이 붙어 있을 뿐** |
| 3~10초 | "첫째, 선납금. 차값의 30에서 50퍼센트를 먼저 내요. 이 돈은 안 돌아와요." | ① 선납금 30~50% (돌려받지 못함) |
| 10~16초 | "둘째, 기간. 60개월로 길게 잡으면 월 금액이 내려가요." | ② 기간 60개월 |
| 16~22초 | "셋째, 주행거리. 1년에 만 킬로로 낮게 잡아요. 넘으면 추가 비용." | ③ 연 1만km 약정 |
| 22~29초 | "넷째, 만기 인수 가격을 높게 잡아요. 인수하려면 마지막에 큰돈이 필요해요." | ④ 만기 인수 가격 ↑ |
| 29~38초 | "그래서 견적 받을 땐 이 네 가지가 같은 조건인지 꼭 물어보세요. 그래야 비교가 돼요." | 선납·기간·주행거리·인수가 **같은 조건으로** |
| 38~42초 | "조건 전부 적은 견적, 필요하시면 프로필 링크로 남겨 주세요." | 조건 다 적은 견적 → 프로필 링크 |

## 업로드 문구 (설명란)

```
"월 10만 원대" 장기렌트 광고, 이 4가지 조건을 확인하세요.

① 선납금 (돌려받지 못하는 돈)
② 계약 기간
③ 연간 주행거리 약정
④ 만기 인수 가격

같은 조건으로 맞춰야 진짜 비교가 됩니다.
조건을 전부 적은 견적 → 프로필 링크

#장기렌트 #장기렌트광고 #선납금 #무보증장기렌트 #신차견적
```

## 썸네일 문구 후보
- 월 10만원대의 비밀
- 이 4개 물어보세요
- 광고 금액의 조건

## 촬영 팁
- 손가락 하나씩 펴면서 ①~④ 말하기 → 자막 번호와 맞추기
- 마지막 장면에 실제 견적 비교표(개인정보 없음)를 0.5초 정도 보여주면 신뢰도 상승
