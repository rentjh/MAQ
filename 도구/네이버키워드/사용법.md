# 네이버 키워드 조회 도구

네이버 검색광고 API로 키워드별 **월간 검색수(PC/모바일), 월평균 클릭수, 클릭률, 경쟁정도, 순위별(1~5위) 예상 입찰가**를 한 번에 조회해 CSV로 저장합니다. 조회 전용이라 광고비가 들지 않습니다.

## 1. API 키 발급 (한 번만)
1. 네이버 검색광고(searchad.naver.com) 광고주 계정 로그인(없으면 무료 가입)
2. 도구 → API 사용 관리 → 네이버 검색광고 API 서비스 신청
3. 표시되는 **고객 ID / 액세스 라이선스 / 비밀키** 3가지 확인

## 2. 키 등록 (채팅에 붙여넣지 마세요)
Claude Code 클라우드 세션 상단의 환경 메뉴 → Edit → 환경 변수(또는 Network secrets)에 아래 이름으로 저장합니다. 저장 후 **새 세션**부터 적용됩니다.

```
NAVER_SA_CUSTOMER_ID=고객ID
NAVER_SA_API_KEY=액세스라이선스
NAVER_SA_SECRET_KEY=비밀키
```

본인 PC에서 직접 실행할 때는 같은 이름으로 환경 변수를 설정하고 `python naver_keywords.py`를 실행하면 됩니다(Python 3, 추가 설치 없음).

## 3. 실행
```
python naver_keywords.py                 # keywords.txt → 결과_키워드조회.csv
python naver_keywords.py --related 10    # 키워드마다 연관 키워드 상위 10개도 함께
```
`keywords.txt`에 조회할 키워드를 한 줄에 하나씩 넣습니다(띄어쓰기는 자동 제거).

## 4. 결과 읽는 법
- **월검색수_합계**: 최근 한 달 검색량. 10 미만은 API가 "< 10"으로 줌(합계 계산에선 5로 처리)
- **월평균클릭**: 광고 클릭 수(전체 광고 합). 이 키워드에서 기대할 수 있는 클릭의 상한선
- **경쟁정도**: 높음/중간/낮음
- **○위_예상입찰가**: 그 순위에 노출되려면 필요한 평균 입찰가(원, VAT 별도 추정치). 실제 클릭당 비용은 보통 입찰가 이하
- 손익 기준: 리드 1건에 쓸 수 있는 최대 클릭비용 ≈ 허용 리드단가 × 랜딩 전환율. 예) 리드단가 38,500원 × 전환율 3% ≈ 클릭당 1,155원
